# claude-sidebar

A Claude Code mod (hooks-module plugin) named `sidebar`.

`/sidebar` toggles a pane with model, turns, burn rate ($/hr, $/turn), context and rate-limit bars with reset times, cost, git branch, ahead/behind and the changed files from `git status` with `+add −del` (click to copy), quick-prompt buttons that fill the composer (edit them in place), todos, subagents, MCP servers with per-server call and token estimates, tool activity (merged repeats, click to copy) and failed calls (click to expand). Click a header to collapse it; ⚙ sets each section to show/auto/hide and the row count, saved across sessions. Refreshes every 5 s.

## Install

This repo is also a plugin marketplace (`claude-sidebar`):

```sh
claude plugin marketplace add msetsma/claude-sidebar
claude plugin install sidebar@claude-sidebar
```

My own setup consumes it through the `dotfiles-mods` marketplace in `~/.dotfiles-agents`, which lists this repo as a GitHub source.

## Layout

```
.claude-plugin/plugin.json        # name, version, description, types
.claude-plugin/marketplace.json   # makes the repo installable as a marketplace
hooks/hooks.json                  # { "modules": ["./register.tsx"] }
hooks/register.tsx                # the mod
types/index.d.ts                  # values the mod keeps in $.state
tests/sidebar.test.ts
```

`.claude-plugin/types/` is generated by Claude Code on load and is gitignored.

## Editing

Clone the repo and work from the clone:

```sh
git clone https://github.com/msetsma/claude-sidebar
cd claude-sidebar
claude plugin validate .
claude plugin test .
```

For a watched dev loop that reloads on every save, start a session with
`claude --plugin-dir <clone>`. Otherwise run `/reload-plugins` in that session
after an edit. An installed copy (`sidebar@claude-sidebar`) is a cached
snapshot, so it only sees pushed changes after
`claude plugin marketplace update claude-sidebar`.
